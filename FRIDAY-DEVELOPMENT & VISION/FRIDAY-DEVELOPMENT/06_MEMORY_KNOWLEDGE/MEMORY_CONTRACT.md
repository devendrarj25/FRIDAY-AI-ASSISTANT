# Memory and Knowledge Development Contract

Memory is not a transcript dump.

Layers:
- working;
- episodic/session;
- semantic;
- procedural;
- experience;
- identity/self.

Every durable item should have:
- stable id;
- source;
- timestamp;
- confidence;
- scope;
- provenance;
- freshness;
- contradiction/supersession state.

Promotion:
`observe → classify → dedupe → verify → consolidate → promote`

Never silently overwrite contradictory durable knowledge. Prefer supersession with provenance.
