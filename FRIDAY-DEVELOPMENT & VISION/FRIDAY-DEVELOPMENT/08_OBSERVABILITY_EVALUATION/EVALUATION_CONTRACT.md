# Evaluation Contract

Evaluate the system, not just the final text.

Dimensions:
- task completion;
- factual correctness;
- tool correctness;
- authorization correctness;
- verification correctness;
- latency;
- token efficiency;
- cost;
- recovery;
- regression;
- user control.

Keep deterministic tests separate from provider-dependent integration tests.

Every regression becomes a reusable evaluation case when practical.
