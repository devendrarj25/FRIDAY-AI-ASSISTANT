# Vision → Development Implementation Roadmap

## Phase 0 — Baseline
Lock current source, contracts and tests.

## Phase 1 — Routing
Implement/maintain source cards, ownership index and context packets.

## Phase 2 — Runtime truth
Unify request/task/run/action/evidence IDs.

## Phase 3 — Durable execution
Checkpointing, idempotency, leases, recovery.

## Phase 4 — Intelligence federation
Policy-aware model/provider selection and safe fallback.

## Phase 5 — Capability federation
Health, provenance, deferred loading, scoped authority.

## Phase 6 — Verification/evidence
Postconditions, receipts, freshness and provenance.

## Phase 7 — Observability/evaluation
End-to-end traces, metrics and regression corpus.

## Phase 8 — Agent runtime
Bounded delegation, parallelism, sandboxing, HITL.

## Phase 9 — Self-improvement
Evidence-driven proposals, evaluator independence, rollback.

## Phase 10 — Hardening
Failure injection, clean-machine validation, supply-chain/release verification.
