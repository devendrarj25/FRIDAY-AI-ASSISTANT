# Implementation Roadmap

## Phase 0 — inventory
Map existing owners and eliminate duplicate responsibilities.

## Phase 1 — contracts
Introduce/standardize IDs, ownership, manifests, lifecycle states and version contracts.

## Phase 2 — registries
Connect existing registry/discovery mechanisms into a single component/runtime view.

## Phase 3 — lifecycle
Implement transactional staging, install, update, repair and recovery journal.

## Phase 4 — storage
Enforce FRIDAY-managed paths and ownership boundaries.

## Phase 5 — build/release
Unify CMD and GitHub build entrypoints and release evidence.

## Phase 6 — uninstall
Implement tracked clean removal and verification.

## Phase 7 — hardening
Run clean-machine, failure-injection, performance and security tests.

## Phase 8 — optimization
Only after correctness: parallel downloads, differential artifacts, caching, lazy activation and richer realtime UI.
