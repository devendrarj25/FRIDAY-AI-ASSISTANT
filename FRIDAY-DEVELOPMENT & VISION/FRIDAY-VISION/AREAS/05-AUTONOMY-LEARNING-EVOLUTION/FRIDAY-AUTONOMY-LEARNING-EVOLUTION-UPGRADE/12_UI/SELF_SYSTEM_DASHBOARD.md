# Self-System UI Blueprint

## Main sections
1. **Autonomy** — level, scoped permissions, budgets, current activity.
2. **Learning** — recent lessons, evidence, confidence, corrections.
3. **Growth** — capability graph, weak areas, next curriculum tasks.
4. **Development** — generated skills/tools/workflows and candidate status.
5. **Experiments** — active/finished experiments, baseline vs candidate metrics.
6. **Evolution Lab** — archive/tree of candidates and Pareto frontier.
7. **Safety** — sandbox state, permissions, rollback readiness, blocked actions.
8. **History** — immutable change lineage.

## Important UX
The user should always be able to answer:
- What is FRIDAY learning?
- Why did she decide to learn it?
- What evidence supports it?
- What changed?
- Did it improve anything?
- Can I undo it?
- What is she currently allowed to change automatically?
