# Experience Fabric

## One evidence record
A trajectory should be reusable by learning, routing, evaluation and debugging.

Fields:
- task fingerprint
- goal
- context class
- chosen route
- model/provider/runtime
- tool calls
- intermediate checkpoints
- output
- evaluator results
- user feedback
- failure/recovery
- latency/cost
- sensitivity
- lesson candidates
- promotion status

## Experience classes
- success
- failure
- correction
- discovery
- experiment
- regression
- recovery

## Replay
A stored experience may be replayed only when inputs are safe to replay and external side effects are disabled or simulated.
