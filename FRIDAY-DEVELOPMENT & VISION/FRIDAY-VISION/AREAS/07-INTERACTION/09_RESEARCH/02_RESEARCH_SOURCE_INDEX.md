# Research Source Index

Primary current sources consulted for this integration:
- A2A Protocol specification and streaming/async guidance — https://a2a-protocol.org/latest/
- LangGraph persistence and HITL/interrupt documentation — https://docs.langchain.com/oss/python/langgraph/persistence and related HITL/interrupt pages
- Model Context Protocol authorization specification — https://modelcontextprotocol.io/specification/2025-06-18/basic/authorization
- Tailscale access control/grants documentation — https://tailscale.com/docs/features/access-control/grants
- OpenTelemetry semantic conventions for events — https://opentelemetry.io/docs/specs/semconv/general/events/

Existing supplied Chat/Voice research was also reconciled into this package, including durable execution, retrieval, observability, MCP/A2A, browser/computer-use, realtime audio, local STT/TTS/VAD, provider routing, privacy, device control, resilience and license/runtime considerations.
