# Voice + Visual Coordination

Voice is not required to carry every detail verbally. For multimodal results, FRIDAY should coordinate speech with the visual surface:

1. acknowledge the request naturally;
2. perform work on the shared runtime;
3. stream a short spoken progress cue when it materially helps;
4. publish visual result/artifact to the active desktop/mobile surface;
5. speak the essential conclusion;
6. offer a focused follow-up such as “I can walk you through the chart” rather than dumping the whole visual into speech.

If no visual surface is connected, the same canonical result must degrade to a spoken/text explanation appropriate to the result type.
