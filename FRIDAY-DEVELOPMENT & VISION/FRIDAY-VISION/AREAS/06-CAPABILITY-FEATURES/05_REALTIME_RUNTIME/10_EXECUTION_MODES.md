# EXECUTION MODES

DIRECT — one capability.
SEQUENTIAL — dependent chain.
PARALLEL — independent fan-out.
DAG — dependency graph.
DELEGATED — remote/specialist agent.
BACKGROUND — durable detached task.
SCHEDULED — time-triggered.
EVENT_DRIVEN — external event trigger.
HUMAN_GATE — pause for approval/input.
SPECULATIVE — bounded parallel candidates.
RECOVERY — resume/reconcile from checkpoint.

Mode selection is broker/composer policy, not a model free-for-all.
