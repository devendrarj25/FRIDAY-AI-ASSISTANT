# Benchmark Lessons

Benchmarks imply that capability breadth alone is not enough.

### GAIA / Web research
Need planning, retrieval, tool selection, multi-step verification and source grounding.

### WebArena / VisualWebArena
Need robust browser state tracking, DOM/visual grounding and recovery.

### OSWorld / OSWorld-Human / OSWorld-MCP
Need efficient action selection, GUI competence, tool invocation, decision quality and step minimization.

### SWE-bench
Need repository understanding, patch execution, tests, debugging and integration verification.

### AgentBench
Need multi-domain, multi-step evaluation rather than chat-only scores.

## FRIDAY benchmark strategy
Create task suites by capability family and measure:
success, correctness, time, actions, retries, cost, policy violations, recovery rate, evidence quality and user intervention rate.
