# 2026 Trends To Build Around
- computer use is becoming a standard agent tool
- tool search/deferred loading reduces context pressure
- agents-as-tools enable hierarchical delegation
- persistent skills/memory are first-class
- background and scheduled agents are normal
- durable execution/checkpoints are required for long work
- multi-device capability routing is emerging
- MCP is an ecosystem interface, not a trust boundary
- A2A enables remote delegation
- evidence, policy and sandboxing must be first-class
- observability and evaluation are becoming part of the runtime
FRIDAY gaps: canonical broker, feature OS, durable task fabric, device registry,
evidence engine, unified policy, artifact graph, health/readiness separation.
