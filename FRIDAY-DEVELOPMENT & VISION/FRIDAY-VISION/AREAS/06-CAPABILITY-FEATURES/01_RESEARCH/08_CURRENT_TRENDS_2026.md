# Current 2026 Trends Relevant to FRIDAY

- Agents are moving from turn-based chat to delegated, long-horizon work.
- Parallel subagents and persistent/background execution are becoming normal.
- Skills, plugins, hooks and MCP are becoming standard extension units.
- Model choice is increasingly runtime routing rather than a fixed model.
- Computer use is moving toward hybrid native API + structured UI + vision.
- Local/small models are being paired with specialized agents to reduce cost and latency.
- Cross-device and remote agent orchestration is emerging.
- Agent security is increasingly about the harness/configuration supply chain, not only model safety.
- Evidence, evaluation and rollback are becoming first-class runtime functions.
