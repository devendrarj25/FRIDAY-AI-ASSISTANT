# Research Methodology

Snapshot date: 2026-09-15.

Sources were prioritized:
1. Official GitHub repositories and first-party documentation.
2. Official product/engineering pages.
3. Benchmark repositories and papers for measurable agent behavior.
4. Community/open-source ecosystems for emerging patterns.

The purpose is not to copy products. It is to extract reusable architectural patterns for FRIDAY.

Research themes:
- capability discovery
- skill/tool/plugin ecosystems
- long-running execution
- memory and context management
- computer use
- multi-agent orchestration
- realtime task UX
- interoperability
- safety and sandboxing
- evaluation and evidence
- extension lifecycle
