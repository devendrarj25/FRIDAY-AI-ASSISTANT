# ULTIMATE DEFINITION OF DONE

FRIDAY's Capability + Feature area is complete only when:

### One source of truth
All executable resources normalize into one capability registry.

### One decision fabric
All capability selection passes through the broker.

### One execution fabric
All durable work uses the task runtime, including background and scheduled work.

### One trust boundary
All side effects pass the same policy/authority system.

### One evidence model
All outcomes can be traced to artifacts, events and verification evidence.

### One extension model
New tool/skill/agent/plugin/MCP/A2A/device/model capability uses an adapter and conformance suite.

### One feature model
User-facing features are capability graphs with explicit success predicates.

### Realtime
Tasks stream progress and survive process/UI restart.

### Computer use
Browser/desktop use has tiered grounding, safe execution and postcondition verification.

### Future proof
Core FRIDAY does not require architectural rewrite for new models, devices, protocols or feature packs.

### AI coding agent ready
A coding agent can inspect this package, inspect FRIDAY, implement phase-by-phase, run tests,
report evidence and safely roll back.
