# UNIFIED FINAL ROADMAP

## Wave 0 — Foundation
Contracts, IDs, events, artifacts, policy facade, adapters.

## Wave 1 — Capability Fabric
Canonical registry, normalizer, readiness, health, evidence, progressive discovery,
broker, cache and explainability.

## Wave 2 — Feature OS
Feature registry, resolver, dependency graph, feature packs, degradation and UI.

## Wave 3 — Execution
Durable tasks, checkpoints, leases, retries, idempotency, scheduler, triggers,
parallelism, streaming and recovery.

## Wave 4 — Computer
Browser + Windows capability providers, perception/grounding, takeover and evidence.

## Wave 5 — Ecosystem
MCP, A2A, plugins, skills, connectors, remote workers and device galaxy.

## Wave 6 — Artifact + Memory
Artifact graph, provenance, evidence store and verified procedural feedback.

## Wave 7 — Quality
Conformance, golden workflows, regression, performance, security, SLOs and canary.

## Wave 8 — UX
Capability Center, Feature Center, Live Task Center, Feature Builder and explainability.

## Wave 9 — Cutover
Broker shadow → partial feature routing → default routing → legacy deprecation.

## Wave 10 — Future-proofing
Versioned contracts, extension SDK, conformance CLI, capability marketplace,
automatic compatibility checks and upgrade migration engine.
