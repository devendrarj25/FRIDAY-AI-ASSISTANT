# Evaluation Architecture

Evaluation levels:
L0 schema
L1 unit
L2 integration
L3 capability smoke
L4 scenario
L5 end-to-end
L6 long-horizon
L7 regression
L8 adversarial/security

Metrics:
success, correctness, groundedness, latency, action count, cost, retries, recovery, intervention, policy compliance, artifact quality.
