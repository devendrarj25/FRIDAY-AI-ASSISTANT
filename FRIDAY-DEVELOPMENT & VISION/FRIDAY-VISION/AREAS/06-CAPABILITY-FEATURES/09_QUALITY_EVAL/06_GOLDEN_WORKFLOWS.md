# GOLDEN WORKFLOWS

Create permanent end-to-end tests for:
1. research → report → export
2. browser → authenticated form → verify
3. desktop → Office document → verify
4. coding → patch → tests → review
5. data → analysis → chart → report
6. email → draft → approval → send → confirmation
7. multi-device delegation → artifact return
8. MCP capability → policy denial/allow → verification
9. long task → restart → resume
10. capability degradation → fallback → outcome verification

Every golden workflow must record trace, artifacts, policy decisions and evidence.
