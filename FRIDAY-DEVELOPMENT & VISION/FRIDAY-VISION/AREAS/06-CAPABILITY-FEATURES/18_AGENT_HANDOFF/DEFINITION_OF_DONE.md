# Definition of Done
- all existing capability types visible in one registry
- all executable capabilities have risk/permission contracts
- every feature resolves to a capability graph
- broker decisions are explainable
- tasks are durable/recoverable
- computer use is tiered and verified
- artifacts have provenance
- MCP/A2A cannot bypass policy
- secrets are scoped
- new models/devices/protocols require adapters, not core rewrites
- packs can be verified/rolled back
- health/readiness/evidence are distinct
- long tasks are observable
- regression/security/recovery tests are enforced
