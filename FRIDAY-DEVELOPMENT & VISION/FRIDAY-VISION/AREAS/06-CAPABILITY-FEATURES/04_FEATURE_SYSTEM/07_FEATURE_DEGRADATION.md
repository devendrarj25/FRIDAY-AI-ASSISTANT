# FEATURE DEGRADATION

Every feature has fallback levels.

Example research:
L0 cached/local knowledge
L1 web search
L2 browser extraction
L3 multi-agent parallel research
L4 human-assisted source resolution

Example desktop action:
L0 API
L1 CLI
L2 UIA
L3 vision
L4 human takeover

Degradation must preserve the feature's success predicate or explicitly tell the user
which guarantee has been relaxed.
