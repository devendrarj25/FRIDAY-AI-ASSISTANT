# Proactive Feature Activation

FRIDAY may proactively suggest or execute features when:
- a user-defined trigger fires
- a task is overdue
- a monitored condition changes
- a project state indicates obvious next work
- a repeated pattern is detected
- a scheduled workflow is due

Guardrails:
- user-configurable autonomy
- quiet hours
- notification policy
- cost budget
- no surprise irreversible actions
- explain why it acted
- easy pause/undo
