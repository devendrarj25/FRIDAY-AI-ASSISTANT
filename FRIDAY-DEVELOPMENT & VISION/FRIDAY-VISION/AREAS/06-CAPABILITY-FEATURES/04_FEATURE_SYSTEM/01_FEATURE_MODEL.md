# Feature System

A Feature is a user-facing outcome, not an implementation primitive.

Example:
`feature.research.report`
composes:
web.search + browser.extract + source.rank + synthesis + citation + document.write + verification

Features declare:
- user intent examples
- capability requirements
- composition template
- UX surfaces
- configuration
- permissions
- readiness checks
- success criteria
- rollback/compensation
- telemetry
- eval suite
