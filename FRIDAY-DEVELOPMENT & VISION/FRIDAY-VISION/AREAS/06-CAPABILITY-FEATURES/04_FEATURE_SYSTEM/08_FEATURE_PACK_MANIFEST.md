# FEATURE PACK MANIFEST

A pack contains:
- pack id/version
- features
- capabilities
- adapters
- dependencies
- platform requirements
- permissions
- data access
- secrets
- UI surfaces
- migrations
- tests
- SBOM/provenance
- signature
- rollback metadata

Install:
discover → inspect → trust → sandbox → dependency resolve → install → verify → enable.

Retirement preserves existing data and explains impacted features.
