# Universal Artifact Model

Artifact types:
text, markdown, JSON, XML, CSV, spreadsheet, document, PDF, image, audio, video, code, dataset, notebook, URL, web page, screenshot, UI state, message, email, calendar event, task result, binary file, directory, device state.

Every artifact:
`id, type, uri, contentHash, mime, metadata, provenance, sensitivity, createdBy, createdAt, parentArtifacts`.
