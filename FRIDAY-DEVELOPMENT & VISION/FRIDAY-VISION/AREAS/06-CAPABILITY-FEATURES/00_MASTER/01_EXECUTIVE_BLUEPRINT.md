# Executive Blueprint

## North-star
FRIDAY becomes a **personal AI operating fabric** rather than a menu of AI features.

### Five planes
1. Experience Plane — chat, voice, desktop, mobile, notifications, dashboards.
2. Intelligence Plane — models, reasoning, routing, planning, memory, learning.
3. Capability Plane — capability registry, broker, composer, skills, tools, agents, workflows.
4. Execution Plane — browser, desktop, terminal, files, apps, APIs, devices, remote workers.
5. Trust Plane — identity, policy, approval, sandbox, secrets, audit, evaluation, rollback.

## Capability lifecycle
`DISCOVERED → NORMALIZED → VERIFIED → ELIGIBLE → SELECTED → PREPARED → RUNNING → COMPLETED → VERIFIED → LEARNED`

Failure/quarantine states:
`BLOCKED | UNAVAILABLE | DEGRADED | TIMEOUT | CANCELLED | FAILED | QUARANTINED | STALE`

## Feature lifecycle
`DISCOVERED → INSTALLED → CONFIGURED → READY → ACTIVE → DEGRADED → UPDATE_AVAILABLE → DISABLED → RETIRED`

## High-level goals
- 100% of executable actions pass through one policy boundary.
- Every capability exposes health + readiness + evidence.
- Long-running tasks survive UI restarts and transient provider failures.
- Capabilities can be discovered from local packages, plugins, MCP, A2A, device nodes and future protocols.
- Tool schemas are progressively disclosed to avoid context bloat.
- User sees why FRIDAY selected a capability and why alternatives were rejected.
