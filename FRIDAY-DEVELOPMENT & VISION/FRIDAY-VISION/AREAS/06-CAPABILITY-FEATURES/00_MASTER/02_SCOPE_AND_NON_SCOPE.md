# Scope

## In scope
Capability registry and contracts, feature registry, broker, composition, real-time execution, task lifecycle, computer use, multimodal artifacts, device/app graph, interoperability, security, verification, observability, marketplace/extension lifecycle, UI surfaces, migration and tests.

## Not in scope
- Rewriting the entire FRIDAY project.
- Replacing the model/provider routing upgrade.
- Replacing autonomy/self-learning architecture.
- Shipping every possible connector in this package.
- Unrestricted self-modification of production code.

## Integration rule
This package is an architectural layer over existing FRIDAY subsystems and previous upgrade packages.
