# Canonical Glossary

Capability — a bounded ability with contract, requirements, permissions and evidence.
Feature — a user-facing outcome implemented by a capability graph.
Tool — executable primitive.
Skill — reusable procedural knowledge/instructions.
Agent — reasoning/execution process with state and goals.
Workflow — explicit graph of steps.
Connector — authenticated service boundary.
Module — persistent runtime subsystem.
Model capability — intelligence property such as vision, coding, long context or reasoning.
Device — execution environment exposing capabilities.
Provider — transport/service implementation.
Artifact — typed input/output with provenance.
Evidence — observable proof supporting readiness or outcome correctness.
Readiness — whether a capability can run now for this task.
Health — whether the component is functioning generally.
Verification — whether the promised result actually occurred.
Policy — rules governing what may happen.
Authority — current permission to perform a specific action.
Feature pack — installable bundle of related features/capabilities.
