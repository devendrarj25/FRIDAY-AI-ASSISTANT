# NORTH STAR

FRIDAY should feel like one system that can accomplish outcomes, while internally it can
select any combination of models, tools, skills, agents, workflows, connectors, applications,
devices, remote workers and future protocols.

The user asks for an outcome.
FRIDAY discovers what is possible, selects what is appropriate, composes a plan, enforces
authority, executes with live state, verifies the outcome, records evidence, and learns
which capability path works best.

The core abstraction is NOT "tool".
The core abstraction is "capability with evidence".
