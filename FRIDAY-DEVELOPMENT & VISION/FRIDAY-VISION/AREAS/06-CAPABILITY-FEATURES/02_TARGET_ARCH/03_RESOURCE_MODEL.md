# Resource Model

Every runtime resource has:
- `id`
- `kind`
- `version`
- `provider`
- `platform`
- `scope`
- `capabilities`
- `requirements`
- `permissions`
- `risk`
- `health`
- `readiness`
- `evidence`
- `telemetry`
- `lifecycle`
- `compatibility`
- `cost`
- `latency`
- `privacy`
- `limits`
- `owner`
- `signature`

Resource kinds:
`model | provider | tool | skill | agent | workflow | connector | module | plugin | device | browser | workspace | feature`
