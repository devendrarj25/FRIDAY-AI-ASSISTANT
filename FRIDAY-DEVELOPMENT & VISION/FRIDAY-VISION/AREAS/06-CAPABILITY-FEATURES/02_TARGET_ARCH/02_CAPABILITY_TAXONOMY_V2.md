# Capability Taxonomy v2

## Capability families
1. Converse — chat, voice, translation, summarization.
2. Perceive — screen, camera, OCR, audio, video, documents.
3. Understand — extraction, classification, entity linking, semantic search.
4. Research — web search, deep research, source synthesis, monitoring.
5. Know — memory, RAG, knowledge graph, project context.
6. Reason — planning, decomposition, debate, critique, verification.
7. Create — text, code, image, audio, video, documents, presentations.
8. Compute — Python, JS, SQL, notebooks, data analysis.
9. Operate — files, terminal, apps, OS controls.
10. Browse — navigation, forms, scraping, transactions.
11. Communicate — email, messaging, calendar, calls, notifications.
12. Automate — workflows, schedules, triggers, event reactions.
13. Develop — codebase analysis, editing, tests, builds, Git, CI/CD.
14. Connect — APIs, MCP, A2A, connectors, webhooks.
15. Coordinate — agents, teams, subagents, remote workers.
16. Manage — projects, tasks, workspaces, artifacts, secrets.
17. Device — PC, mobile, browser, IoT, Home Assistant, peripherals.
18. Monitor — health, uptime, prices, jobs, alerts, changes.
19. Learn — feedback, demonstrations, skill synthesis, evaluation.
20. Govern — permissions, audit, policy, compliance, rollback.
21. Optimize — routing, caching, cost, latency, quality.
22. Recover — retry, checkpoint, rewind, failover, repair.
23. Extend — plugins, skills, capability packages, marketplace.
