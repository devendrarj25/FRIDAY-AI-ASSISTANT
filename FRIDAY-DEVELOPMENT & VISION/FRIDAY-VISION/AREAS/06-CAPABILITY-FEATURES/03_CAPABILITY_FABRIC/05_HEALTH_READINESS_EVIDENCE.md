# Health, Readiness and Evidence

Do not collapse these concepts.

### Health
Is the component functioning in general?

### Readiness
Can this exact capability execute now for this exact task?

### Evidence
How strong is the proof that it works?

### Verification ladder
L0 manifest valid
L1 loaded
L2 dependencies resolved
L3 smoke test passed
L4 live execution passed
L5 outcome verified

### Quarantine
Repeated failures, security anomalies, schema mismatch or suspicious behavior can quarantine a component while preserving its package for diagnosis.
