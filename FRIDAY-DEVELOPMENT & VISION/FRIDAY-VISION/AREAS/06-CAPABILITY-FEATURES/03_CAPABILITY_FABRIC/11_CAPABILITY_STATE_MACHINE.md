# CAPABILITY STATE MACHINE

DISCOVERED
→ NORMALIZED
→ INSPECTED
→ VERIFIED
→ ELIGIBLE
→ SELECTED
→ PREPARED
→ RUNNING
→ COMPLETED
→ OUTCOME_VERIFIED
→ LEARNED

Side states:
BLOCKED, UNAVAILABLE, DEGRADED, STALE, FAILED, QUARANTINED, RETIRED.

Transitions require explicit events. No UI flag may silently promote a capability.
