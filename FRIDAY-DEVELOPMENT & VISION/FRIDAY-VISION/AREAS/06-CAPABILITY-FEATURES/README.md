## Critical implementation instruction
Do NOT replace FRIDAY blindly. Build adapters around the existing capability systems,
run broker shadow mode, prove parity, then cut over gradually.

## Important
This package is an architecture/implementation specification, not a claim that every target
feature is already implemented in the FRIDAY source. The goal is to give an AI coding agent
a complete, unambiguous blueprint to implement and verify the target system.
