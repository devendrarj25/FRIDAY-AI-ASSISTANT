# INTEROP TRUST LAYERS

Layer 0 identity: who supplied this capability?
Layer 1 provenance: where did it come from?
Layer 2 contract: what does it claim?
Layer 3 sandbox: what can it access?
Layer 4 policy: what may it do for this task?
Layer 5 runtime: did it execute?
Layer 6 evidence: did it achieve the claimed result?
Layer 7 reputation: how has it performed historically?

Interop components never inherit trust solely because they speak MCP/A2A.
