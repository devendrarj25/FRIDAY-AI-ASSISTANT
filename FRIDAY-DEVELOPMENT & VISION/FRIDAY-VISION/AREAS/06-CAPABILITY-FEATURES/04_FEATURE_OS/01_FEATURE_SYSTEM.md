# Feature Operating System
Feature = stable user-facing outcome backed by capabilities.
Lifecycle: discovered → installed → configured → ready → active → degraded → disabled → retired.
Feature contract: id, intent, required/optional capabilities, triggers, settings, UI,
voice surface, success criteria, policy, telemetry and rollback.
Feature packs: communication, productivity, knowledge, browser, desktop, coding,
documents, data, media, automation, research, personal AI, devices, business, system.
