# Implementation Plan

## P0 — Foundations
Contracts, schemas, event bus, registry, adapters, telemetry.

## P1 — Canonical broker
Hard filters, scoring, explainability, progressive disclosure.

## P2 — Composition
DAGs, parallelism, delegation, verifiers, compensation.

## P3 — Durable runtime
Task persistence, checkpoint, resume, cancellation, scheduler.

## P4 — Feature system
Feature registry, feature compiler, readiness, UX.

## P5 — Computer fabric
Browser + desktop + perception + action + takeover.

## P6 — Interop
MCP/A2A/plugin/connector adapters.

## P7 — Quality
Benchmark suites, evidence, regression, health/quarantine.

## P8 — Proactive/autonomous
Triggers, monitors, background work, user-defined autonomy.

## P9 — Ecosystem
Marketplace, capability packs, signed packages, remote workers.

## P10 — Optimization
Speculative execution, caching, small-model routing, adaptive planning.
