# Self-Improvement Factory

Pipeline:
observe → diagnose → formulate hypothesis → create isolated candidate → static checks → focused tests → regression suite → adversarial/failure tests → resource/security checks → canary → monitor → promote or rollback.

The factory may improve code, prompts, routing policies, skills, workflows, capability metadata and evaluation suites within its authority. Governance can forbid classes of changes entirely.

The baseline remains immutable until promotion. Every candidate has parent version, diff, test evidence, evaluator version and rollback pointer.
