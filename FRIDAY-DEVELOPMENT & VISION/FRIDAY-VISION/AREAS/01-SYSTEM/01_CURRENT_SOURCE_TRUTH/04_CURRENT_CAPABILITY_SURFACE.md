# Current Capability Surface

The current feature catalog documents: **214 Skills**, **177 Tools**, **98 Agents**, **78 Plugins**, **116 Workflows**, **76 Modules**, **113 Connectors**, and **27 Kernel tools**. Discovery is already centralized through capability trees/registries and the Electron capability runtime.

The upgrade must not replace these with a new hardcoded master list. Instead, normalize metadata and lifecycle around the existing registry so every new capability becomes visible to all supported experience endpoints automatically.

Current major surfaces include Chat, Voice, Manual/Auto, phone companion, local/cloud models, browser, terminal, sandbox, tasks, doctor, logs, library/projects, PC control, character/companion, camera ingest, conversation continuity, workflow visual builder and system/status sections.
