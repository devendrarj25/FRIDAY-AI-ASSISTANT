# Package Structure

`00_MASTER_CONTROL` controls interpretation. `01_CURRENT_SOURCE_TRUTH` captures the actual checkout. `02_TARGET_SYSTEM` defines the final FRIDAY OS architecture. `03_COGNITIVE_SYSTEM` defines brain/context/affect/identity. `04_MEMORY_KNOWLEDGE` defines continuity and retrieval. `05_PLANNING_ROUTING` defines adaptive orchestration. `06_MODEL_FEDERATION` defines model selection and local/cloud federation. `07_CAPABILITY_FABRIC` defines capabilities/tools/skills/agents/modules/connectors. `08_EXECUTION` defines computer/browser/device/code execution. `09_ARTIFACTS` defines generation and analysis of files/media. `10_REALTIME_ACTIVITY` defines live execution visualization. `11_EXPERIENCE_MODES` defines Chat/Voice/Mobile × Manual/Auto. `12_DISTRIBUTED_COMPANION` defines remote continuity. `13_SELF_LEARNING` and `14_SELF_DEVELOPMENT` define learning and governed code evolution. `15_GOVERNANCE_SECURITY` defines immutable policy and authority. `16_DURABILITY_RESILIENCE` defines recovery. `17_OBSERVABILITY_EVALUATION` defines evidence. `18_PERFORMANCE_RESOURCE` defines budgets. `19_CONTRACTS` contains machine-readable contracts. `20_DIAGRAMS` contains SVG block/wiring diagrams. `21_RESEARCH` contains external research synthesis. `22_IMPLEMENTATION` contains source-level migration instructions. `23_AI_HANDOFF` contains the master instruction for the implementing AI. `24_ACCEPTANCE` contains completion criteria. `25_DOCUMENT_CONTROL` prevents documentation drift.

No historical ZIP is included. No Mermaid source is included. The package contains consolidated knowledge only.
