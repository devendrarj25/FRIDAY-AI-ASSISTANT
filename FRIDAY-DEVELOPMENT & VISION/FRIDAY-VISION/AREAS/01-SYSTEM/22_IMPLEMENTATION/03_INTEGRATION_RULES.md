# Integration Rules

1. Search before create.
2. Extend before replace.
3. Adapt existing registries instead of introducing a new registry.
4. Keep UI state downstream of runtime truth.
5. Keep model selection downstream of policy/data eligibility.
6. Keep tool execution downstream of authority.
7. Keep self-development downstream of sandbox + tests + build + approval.
8. Keep Companion downstream of the same task/event fabric.
9. Keep generated artifacts downstream of validation.
10. Keep documentation synchronized with actual code.
11. If two existing owners overlap, consolidate through a compatibility adapter before removing anything.
12. Do not change build/installer/release merely to make architecture cleaner.
