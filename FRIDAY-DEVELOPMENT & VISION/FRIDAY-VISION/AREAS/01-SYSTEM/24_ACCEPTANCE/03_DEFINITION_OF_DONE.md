# Definition of Done

A capability is done only when:
- its canonical owner is identified;
- contracts are defined;
- existing registries are reused;
- governance is wired;
- durable state is handled where needed;
- actual runtime events are emitted;
- tests cover the requested behavior only;
- build/runtime evidence exists;
- relevant regression checks pass;
- documentation reflects the actual implementation;
- no protected build/release path was silently altered.

Architecture documents alone do not satisfy implementation completion.
