# Browser / Computer Experience Memory

FRIDAY may learn reusable navigation knowledge such as:
- site/app landmarks;
- stable labels and accessibility names;
- workflow sequences;
- known login/approval boundaries;
- common failure modes;
- successful fallback strategies;
- verification checkpoints.

Live application state always outranks stored memory. If a learned selector or workflow fails, FRIDAY re-observes the current environment, records the failure and can update the experience memory only after successful verification.
