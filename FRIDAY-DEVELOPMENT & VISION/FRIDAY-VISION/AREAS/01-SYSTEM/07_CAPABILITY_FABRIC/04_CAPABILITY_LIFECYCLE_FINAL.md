# Capability Lifecycle — Final

Discover → inspect metadata → security/policy review → install/register → health probe → compatibility test → publish to shared registry → route → observe → version → deprecate → retire.

Capability classes remain unified with the existing FRIDAY catalog: skills, tools, agents, plugins, workflows, modules, connectors, kernel tools and device capabilities. Do not introduce a parallel registry.

External capability protocols such as MCP and A2A are adapters into the same fabric, not separate universes.
