# FRIDAY AI OS Layer Model

FRIDAY is not merely an LLM wrapper. The target is an operating layer for intelligent work.

| Layer | Responsibility | Durable? |
|---|---|---|
| Identity | owner, FRIDAY identity, preferences, boundaries | yes |
| Policy | authority, risk, approvals, privacy, secrets | yes |
| World Model | entities, relationships, temporal facts, environment | yes |
| Memory | episodic, semantic, procedural, preference, task memory | yes |
| Goals | goals, commitments, priorities, deadlines, routines | yes |
| Executive | attention, planning, routing, delegation, replanning | yes |
| Capability Fabric | skills/tools/agents/workflows/connectors/devices | registry |
| Model Federation | local/cloud models and modality specialists | registry |
| Execution Fabric | OS/browser/code/API/device actions | journal |
| Artifact Fabric | files, documents, images, audio, video, code, structured data | yes |
| Event Fabric | realtime state/events/notifications/activity | journal |
| Evaluation | quality, reliability, cost, latency, safety | yes |
| Experience Shells | Chat, Voice, Mobile and existing UI | no task truth |

The model is a replaceable cognitive worker inside this operating layer, never the operating system itself.
