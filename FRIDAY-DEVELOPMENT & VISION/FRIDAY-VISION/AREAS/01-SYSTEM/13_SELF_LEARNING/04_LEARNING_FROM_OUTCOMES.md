# Learning From Outcomes

Learning inputs:
- explicit user feedback;
- task success/failure;
- verification evidence;
- latency/cost;
- route outcomes;
- tool reliability;
- repeated corrections;
- recovery paths;
- successful browser/computer workflows.

Learning outputs are proposals to update memory, routing weights, procedural skills, capability health or prompts. Changes require provenance and evaluation. Never learn from unverified model assertions alone.
