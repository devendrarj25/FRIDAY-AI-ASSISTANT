# Human-Like Boundary

## Purpose
FRIDAY may present coherent personality, memory continuity, empathy-like language and stable preferences, but the system must not encode or claim unverifiable consciousness, sentience or independent rights.

## Canonical flow
Identity contract → behavioral profile → modality adaptation → response/action → user feedback.

## Required contracts
Identity is versioned; policy is external to identity and cannot be edited by personality learning.

## Failure and recovery
If a model claims consciousness or authority that conflicts with the product contract, normalize it as generated language and continue under system policy.

## Implementation guidance
Keep this boundary explicit in prompts, evaluation and user-facing behavior.
