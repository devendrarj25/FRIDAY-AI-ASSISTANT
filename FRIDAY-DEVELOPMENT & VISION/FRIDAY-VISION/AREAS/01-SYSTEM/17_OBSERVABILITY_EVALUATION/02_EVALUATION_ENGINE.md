# Evaluation Engine

## Purpose
Evaluate task correctness, policy compliance, latency, cost, tool reliability, user feedback and regression risk.

## Canonical flow
Expected outcome → execution evidence → evaluator → score/failure taxonomy → learning or rollback decision.

## Required contracts
Evaluation results reference task/route/capability/model versions.

## Failure and recovery
Do not reward unsafe shortcuts merely because they are faster.

## Implementation guidance
Integrate intelligence benchmark, doctor and self-learning.
