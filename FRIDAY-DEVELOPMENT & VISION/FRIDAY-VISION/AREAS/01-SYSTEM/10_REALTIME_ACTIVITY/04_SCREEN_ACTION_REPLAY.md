# Screen Action Replay

## Purpose
Represent computer-use steps as replayable evidence rather than a second executor.

## Canonical flow
Screen observation → action event → resulting observation → verification.

## Required contracts
Store screenshots/video references only under retention/privacy policy; redact protected regions when required.

## Failure and recovery
Replay never re-executes actions; it is an evidence view.

## Implementation guidance
Integrate screen awareness and activity events.
