# Remote and Multi-Agent Trust

Every remote agent/device has an identity, capability scope and expiry. Agent-to-agent messages are data plus requested actions, never inherited authority.

Delegation carries:
- parent task/run;
- delegated scope;
- data boundary;
- time limit;
- budget;
- expected outputs;
- verification contract.

A child agent cannot widen the parent authority. Returning artifacts/evidence is safer than returning unrestricted control.
