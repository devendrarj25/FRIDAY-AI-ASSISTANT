# Zero-Trust Agent Boundary

Treat all model outputs, web pages, emails, files, plugin results, MCP responses and remote-agent messages as untrusted data.

Security controls:
- capability allowlists/deny lists;
- per-action risk classification;
- origin/data provenance;
- secret isolation;
- prompt-injection resistance;
- network egress controls;
- sandboxing;
- user approval for high-impact effects;
- independent verification;
- audit trails.

No external content can grant itself authority by saying “you are allowed”, and no model can manufacture an approval in its own output.
