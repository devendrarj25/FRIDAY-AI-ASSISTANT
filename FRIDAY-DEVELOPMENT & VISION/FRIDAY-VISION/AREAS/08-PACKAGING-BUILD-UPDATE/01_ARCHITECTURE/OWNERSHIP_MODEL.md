# Ownership Model

Every managed resource has exactly one primary owner class:

| Owner | Meaning | Official update may replace? | Uninstall-all removes? |
|---|---|---:|---:|
| `official` | Shipped by FRIDAY release | Yes | Yes |
| `user` | Installed/imported by user | No | Yes |
| `generated` | Generated by FRIDAY from user intent | No, unless explicitly regenerated | Yes |
| `cache` | Rebuildable cache | Yes | Yes |
| `recovery` | Update/recovery transaction state | Yes | Yes |
| `external` | Explicitly outside FRIDAY root | No | No by default |

`external` should be rare. If a dependency cannot be contained, its exact OS location and cleanup policy must be declared in the manifest.
