# READ FIRST

1. Treat this package as the contract for the packaging/build/update area.
2. Read `00_MASTER/DEFINITION_OF_DONE.md` before implementation.
3. Read `01_ARCHITECTURE/TARGET_ARCHITECTURE.md` and `SOURCE_VS_RUNTIME.md`.
4. Read `02_VERSIONING/VERSION_CONTRACT.md` before changing version code.
5. Read `03_BUILD/BUILD_CONTRACT.md` and `03_BUILD/DEPENDENCY_FREEZE.md` before changing build scripts.
6. Read `04_RUNTIME/RUNTIME_AND_COMPONENT_OWNERSHIP.md` before changing runtime/component paths.
7. Read `05_INSTALLER/INSTALL_MANAGER.md` and `05_INSTALLER/FRIDAY_ROOT_LAYOUT.md` before changing installation.
8. Read `06_UPDATES/UPDATE_ARCHITECTURE.md`, `UPDATE_TRANSACTION.md`, and `USER_COMPONENT_PRESERVATION.md` before changing updater behavior.
9. Read `07_GITHUB/GITHUB_ACTIONS_CONTRACT.md` and `RELEASE_EVIDENCE.md` before changing CI/release workflows.
10. Read `08_WINDOWS/WINDOWS_DISTRIBUTION.md` before selecting a packaging target.
11. Read `09_DOCUMENTATION/DOCUMENT_SYNC.md` before adding manual version strings to docs.
12. Read `12_FILE_MAP/FILE_BY_FILE_PLAN.md` before implementation.
13. Use only SVG diagrams. No PNG and no Mermaid are required by this package.
